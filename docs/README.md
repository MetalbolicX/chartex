
# chartex

> You don't need to leave the terminal to visualize your dataset.

chartex renders compact, beautiful ASCII charts for terminals and scripts from plain JSON/NDJSON/CSV input. Written in **ReScript** and shipped as a tiny ESM library.

## Quick Install

```sh
npm install chartex
```
