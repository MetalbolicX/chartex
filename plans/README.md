## Findings considered and rejected

- **Perf work on Pie/Donut string accumulation**: rejected — the committed
  benchmark (`bench/RESULTS.md`, landing via plan 006) measured
  `Array.joinWith`/`Buffer` as 14–21% SLOWER for these chart shapes; current
  `string ++` is the measured optimum at realistic sizes. Revisit only if
  radius/streaming workloads change (conditions listed in RESULTS.md).
- **`ensureKeyType` runtime key-type validation**: rejected during the 007
  exploration — every chart config key is statically `string`
  (`src/Config/Types.res`); a runtime check is dead code by construction.
- **Duplicate-key rejection**: rejected during the 007 exploration —
  Sparkline/Scatter group repeated keys into series and Pie/Donut render
  repeated legend rows by design; rejecting duplicates would break
  intentional behavior.
- **ChartRender module (escapeCell/colorize/formatValue/header)**: rejected —
  the original 007 draft assumed `%{...}`/`%{RESET}` primitives that do not
  exist anywhere in this codebase; no consumer for the helpers. Revisit only
  if a terminal-styling feature actually lands.
