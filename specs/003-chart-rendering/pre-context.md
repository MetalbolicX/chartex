- Render pie/donut chart with proportional segments
- Render gauge showing percentage
- Render bullet chart for comparisons
- Render sparkline for inline data
- Render scatter plot with optional legend

**Edge Cases**:
- Empty data arrays
- Single data point
- Very large values exceeding terminal width
- Zero values
