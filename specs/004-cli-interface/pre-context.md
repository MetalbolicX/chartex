**Existing Feature Summary**: Command-line interface for using chartex from terminal — parses arguments, reads JSON input, adapts data, renders chart, outputs to stdout.

**Existing User Scenarios**:
- Parse --type bar --key-field key --value-field value arguments
- Read JSON array from stdin or file
- Adapt JSON to internal chart data types
- Render chart using appropriate renderer
- Output ASCII chart to stdout

**Edge Cases**:
- Invalid JSON input
- Missing required fields
- Type conversion failures
- Empty input data
