## F003: Chart Rendering

### Bar Chart Algorithm

```
1. Calculate max value from data
2. Determine scale factor (terminal width / max value)
3. For each data point:
   - Calculate bar length = value * scale
   - Render bar with optional style
4. Render labels and axis
```

**Source**: `src/Charts/Bar.res`

### Pie/Donut Chart Algorithm

```
1. Calculate total value
2. For each segment:
   - Calculate angle = (value / total) * 360
   - Render arc using block characters
3. For Donut: render inner circle
```

**Source**: `src/Charts/Pie.res`, `src/Charts/Donut.res`

### Gauge Chart Algorithm

```
1. Normalize value to 0-100 range
2. Calculate filled segments
3. Render gauge with optional background
```

**Source**: `src/Charts/Gauge.res`

### Bullet Chart Algorithm

```
1. Render primary measure bar
2. Render bullet marker
3. Render ranges (optional)
4. Render labels
```

**Source**: `src/Charts/Bullet.res`

### Sparkline Algorithm

```
1. Determine min/max for data range
2. Calculate y-axis scale
3. Map each point to character position
4. Render line using block characters
```

**Source**: `src/Charts/Sparkline.res`

### Scatter Plot Algorithm

```
1. Normalize x/y to terminal dimensions
2. Map points to grid positions
3. Render with optional legend
```

**Source**: `src/Charts/Scatter.res`
