Short, high-signal instructions for automated agents working on this repo.

Workspace essentials
- Always run commands from the repository root.
- Node engine: requires Node >= 22.0.0 (package.json "engines"). Older Node will fail builds/tests.

Sources of truth
- ReScript sources: src/**/*.res (and .resi). These are the editable sources.
- Generated artifacts: src/**/*.res.mjs and bin/ChartexCli.res.mjs are generated by the ReScript compiler — do NOT edit .res.mjs files directly. Run the ReScript build instead.

Common commands (run from project root)
- Compile ReScript once: npm run res:build
- ReScript watch (dev): npm run res:dev
- Clean ReScript outputs: npm run res:clean
- Run the bundled CLI build (compile + bundle): npm run cli:build
  - This is required before using the example scripts in /examples — examples/README.md explicitly requires it.
- Bundle only: npm run bundle
- Run tests (ReScript test runner): npm run res:test
- Build package artifacts (DEFS / dist): npm run build (runs tsdown; dist/* files are referenced in package.json exports and are required for publishing/consumers)
- Start (runtime): npm run start (runs node dist/main.mjs) — only useful after producing dist files.
- Serve docs: npm run docs (runs docsify serve docs) — this may require docsify to be available in PATH (not bundled in devDependencies).

Running the CLI locally
- Examples and CI invoke the CLI directly with Node: use node bin/ChartexCli.res.mjs --chart ...
- The bin script in package.json points to bin/ChartexCli.res.mjs which imports compiled modules under src/. You can run that file directly with node for manual testing.

What to edit
- Edit .res / .resi files in src/ (ReScript source). After changes run npm run res:build to regenerate .res.mjs files.
- Do not hand-edit generated .res.mjs files or the bin/ChartexCli.res.mjs file — they will be overwritten by the compiler.

Publishing / distribution notes
- package.json exports reference files under dist/ (index.d.mts, index.mjs, etc). Ensure npm run build (tsdown) and any bundling steps are run before publishing.

Examples / reproducible commands (quick)
- Build CLI and run one example (from repo root):
  npm run cli:build
  node bin/ChartexCli.res.mjs --file examples/data/sales.csv --chart bar --key department --value growth
- Pipe NDJSON into CLI (example):
  cat examples/data/sales.ndjson | node bin/ChartexCli.res.mjs --chart bar --key department --value revenue

Other gotchas
- No lockfiles are committed; dependency resolution depends on user's package manager state. Prefer using the same Node major version (>=22).
- The project is a ReScript codebase: expect two file kinds in src/ (.res source + .res.mjs generated). Follow the edit/run flow above.

Where to look next
- examples/README.md — runnable examples and explicit note: "Build the CLI first: npm run cli:build".
- package.json — scripts and Node engine requirement.

If you are uncertain about a command, read package.json scripts and examples/README.md first.
